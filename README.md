# Orderly - Simple Point of Sale (POS)

Hi Developer,

Welcome to **Orderly**! This project is a streamlined, professional Point of Sale (POS) application specifically designed for restaurants and eateries. Built with Laravel 12 and Filament PHP 5, it prioritizes simplicity without compromising on essential professional features such as security, activity logging, and rigorous testing.

This repository serves as a robust starting point for building specialized POS systems or learning modern TALL stack development with a focus on real-world reliability.

## Dazzling Tech Stack

- [Laravel 12](https://laravel.com/) - Backend PHP Framework
- [Filament PHP 5](https://filamentphp.com/) - TALL Stack Admin Panel
- [PHP 8.2+](https://www.php.net/) - Server-side language
- [PostgreSQL](https://www.postgresql.org/) - Database Management
- [Tailwind CSS](https://tailwindcss.com/) - CSS Framework

## Credentials & Environment

While this repository is open for learning and collaboration, please note that all forms of credentials, API keys (including `.env`), and environment configurations are **not provided for the public**. Access to production databases and sensitive configuration remains restricted for security reasons.

If you are interested in deploying this project or require a specific configuration guide, please ensure you follow standard Laravel installation procedures and secure your environment variables accordingly.
